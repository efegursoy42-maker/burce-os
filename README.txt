BURÇE OS — DEMO v1
==================
Açmak için: index.html dosyasına çift tıkla (Chrome/Edge).

Klasörler:
  index.html  → sayfa iskeleti
  style.css   → tüm görünüm (renkler en üstte :root içinde)
  app.js      → pencere sistemi (dokunmana gerek yok)
  data.js     → TÜM İÇERİK: projeler, görseller, bio, linkler
  assets/img/full   → büyük görseller (~1920px .webp)
  assets/img/thumb  → küçük önizlemeler (~640px .webp)

Yeni proje / orijinal görsel eklemek:
  1) Görseli .webp olarak full/ ve thumb/ klasörlerine koy
  2) data.js'te ilgili projenin img listesine dosya adını yaz
Not: Şu anki görseller PDF sayfalarından alınmıştır (geçici).
